Malvado is a game engine inspired by DIV Games Studio. Its C core runs games written in C or Lua. Malvado 2 is in development, so its API can change.

## Start here

[Build Malvado and run Hello World](./getting-started/), then look at the [Lua and C process examples](./samples/).
