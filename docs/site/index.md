# Welcome to Malvado

Malvado is a game runtime with C and Lua APIs. Version 2 is in development.

Start with the [project README](https://github.com/jepemo/malvado/blob/master/README.md) for setup and a first example. Then explore these guides:

- [C API and processes](https://github.com/jepemo/malvado/blob/master/docs/api/c-contract.md)
- [Lua API and processes](https://github.com/jepemo/malvado/blob/master/docs/api/lua-processes.md)
- [Images and atlas sprites](https://github.com/jepemo/malvado/blob/master/docs/api/images.md)
- [Audio](https://github.com/jepemo/malvado/blob/master/docs/api/audio.md)
- [Examples](https://github.com/jepemo/malvado/blob/master/docs/examples/README.md)

These links follow the development branch. Features can change before release.

The [previous documentation](https://jepemo.github.io/malvado/legacy/) is also available after deployment.
