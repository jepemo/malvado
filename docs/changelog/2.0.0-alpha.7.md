# Malvado 2.0.0-alpha.7

## Highlights

This prerelease adds an experimental Rust gameplay API on the C and Lua
process scheduler. Rust games can run owned async processes, use checked
handles and cancel processes through the native runtime.

## Added

- Native gameplay APIs cover graphics, images, animation, cameras, text,
  input, audio, collision and movement in tile worlds.
- On macOS arm64 and Linux x86_64, create a Rust starter with
  `malvado new --lang rust my-game`. Use `check`, `build`, `run` and
  `export` from its project directory. The exported game runs without an
  installed SDK. See the [SDK guide](../site/sdk.md) and
  [Rust process guide](../api/rust-processes.md).

## Known limitations

The SDKs are Debug builds. Windows and Android platform verification,
physical-device checks and audible audio checks were still pending.
Malvado does not sign or notarize macOS exports. Game-specific third-party
runtimes require manual packaging. The 2.0 APIs are evolving, and 1.0 games
need a source port.
