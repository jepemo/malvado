# Malvado 2.0.0-beta.1

## Highlights

This prerelease adds reference documentation and matching starter, process
and PNG lessons for C, Lua and experimental Rust. It also adds a verified
source archive with an exact revision and a SHA-256 checksum.

## Added

- SDK archives support macOS arm64, Linux x86_64 and Windows x64 MSVC.
  Windows authoring exports to a native x64 folder.
- All three languages can export Android arm64 APKs and AABs from the
  supported macOS and Linux hosts. Use the matching Android target SDK and
  pinned Android tools. See the [SDK guide](../site/sdk.md).
- The release bundle includes versioned documentation and dependency notices.

## Breaking changes

When upgrading Rust code from 2.0.0-alpha.7, replace `malvado::Engine` with
`malvado::Game`. The new name is used in the templates and reference. See
the [Rust rename guide](../development/rust-game-migration.md).

## Upgrade from earlier 2.0 prereleases

Replace your SDK. For experimental Rust, update the path to the Rust crate
from the same SDK and rebuild. The Rust crate checks the native release and
ABI when it builds against the SDK.

## Known limitations

Windows x64 and Android arm64 support is beta. Desktop exports target the
authoring host. Android export requires macOS or Linux. Malvado does not
sign or notarize macOS app exports. Games that depend on additional runtimes
must supply them with their required notices. Physical-device and audible
audio checks were still pending.
