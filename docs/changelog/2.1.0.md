# Malvado 2.1.0

## Highlights

- In Lua, call operations as optional methods on handles, play overlapping
  copies of a sound, and organize assets under a game directory. Mouse and
  controller events can detect presses and releases. The game can resize its
  window.
- In experimental Rust, start a windowed game with a managed runner and spawn
  processes with fewer arguments. Headless games and hosts with their own loop
  can still tick manually.
- C gains mouse and controller press and release queries on the shared input
  API. See the [input guide](../api/keyboard.md).
- The CLI and SDK support C, Lua and experimental Rust. macOS arm64 and Linux
  x86_64 are stable desktop targets. Windows x64 and Android arm64 remain beta.

## Breaking changes

The following steps apply when upgrading from 2.0.0 to 2.1.0.

- **Lua fades.** Set durations in milliseconds of simulation time. At
  60 ticks per second, replace `mv.fade_off(30)` with `mv.fade_off(500)`
  for a half-second fade. The default changes from 16 ticks to 250 ms.
  Pass a named table to `fade_to`. Read alpha from `mv.fade_color()[4]`
  instead of taking the fourth return value. See the
  [fade guide](../api/fades.md).
- **Lua drawing.** Shape calls use named fields and can set color per command.
  Replace `mv.draw_box(20, 20, 120, 80)` with
  `mv.draw_rect {x = 20, y = 20, width = 100, height = 60}`. Use
  `filled = false` for an outline. Replace `draw_fcircle` with
  `draw_circle` using the default filled mode. Update the color arguments
  and check shape placement against the game's camera. See the
  [drawing guide](../api/drawing.md) and [Lua API conventions](../api/lua-processes.md#lua-api-conventions).
- **Lua sound and music.** A loaded sound is now a reusable sample. Each call
  to `play_sound` starts an independent voice. Pass initial volume in the
  options table and pass the returned voice to playback controls. Check for
  `nil` when all 32 playback slots are occupied. Change
  `mv.load_music("music.ogg", true)` to
  `mv.load_music("music.ogg", {loop = true})` for a looping track. See the
  [audio guide](../api/audio.md).
- **Lua input.** Replace `mv.key_down(KEY_SPACE)` with
  `mv.key(KEY_SPACE)` for held-state checks. The input namespace exposes the
  same operation. See the [input guide](../api/keyboard.md).
- **Lua text.** Font descriptors now hold typography and size. Set color on
  each text. Update text with `mv.change_text(id, {color = mv.colors.WHITE})`
  instead of mutating a shared font color. See the [text guide](../api/text.md#lua-persistent-text).
- **Lua asset paths.** Relative paths now use the game asset directory.
  Update paths that depended on the caller's working directory. For a game
  started from outside the CLI, check the setup in
  [game asset paths](../api/asset-sources.md#game-asset-paths).
- **Experimental Rust.** Rebuild against the 2.1.0 native SDK and its matching
  crate sources. Use `game.spawn(worker)` for defaults and
  `game.spawn_with(options, worker)` for explicit options. Use
  `Some(fps)` for an explicit rate. See the
  [spawning and windowed code migration guide](../development/rust-game-migration.md#migrate-spawning-and-windowed-code).

### Control Lua sound playback

In 2.0.0, pass the sound to the controls.

```lua
mv.sound_volume(jump, 0.5)
mv.play_sound(jump)
mv.stop_sound(jump)
```

In 2.1.0, use the voice returned for that playback.

```lua
local voice = mv.play_sound(jump, {volume = 0.5})
if voice then
    mv.stop_sound(voice)
end
```

## Install

Use the [installation guide](https://malvado.dev/2.1.0/getting-started/#install-the-sdk).
For a new C or Rust game, pass `--lang c` or `--lang rust` to
`malvado new`. Lua remains the default.

## Known limitations

Clean-machine exports, physical-device checks and audible audio still have
open manual verification items.
