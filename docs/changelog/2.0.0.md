# Malvado 2.0.0

## Highlights

- Write 2D games in C, Lua or experimental Rust. Each character or effect can
  run as its own process on the shared scheduler.
- Use the SDK and CLI to create, check, run and export native games.
- The SDKs, source archive and versioned documentation identify the same
  source revision. Verify downloads using the supplied SHA-256 checksums.

## Breaking changes

Malvado 1.0 games need a source port to run on 2.0. The new scheduler and
native C API use a new process and resource contract. Start with a 2.0
project, then move gameplay and assets into it. Review the
[gameplay guides](../site/api.md) and the
[compatibility policy](../api/compatibility.md). Check FPG compatibility
for each asset format separately.

If you used a 2.0 prerelease, replace its SDK with the 2.0.0 SDK. For Rust
projects, point Cargo at the crate from the same SDK and rebuild the game.

## Install

Follow the [SDK setup](https://malvado.dev/2.0.0/getting-started/). After
installation, create and run the Lua starter.

```sh
malvado new my-game
cd my-game
malvado run
```

## Known limitations

macOS arm64 and Linux x86_64 are stable desktop targets. Windows x64 and
Android arm64 have beta platform support. Rust gameplay is experimental.
Clean-machine exports, physical controllers, physical Android devices and
audible audio had open manual checks at publication.
