# Malvado 1.0

## Highlights

The first Malvado release introduced the basic process workflow and graphic
packages (FPG) backed by images, directories or ZIP archives.

## Added

- Drawing primitives and LÖVE aliases for screen, text and fonts, keyboard
  and mouse input, and fade transitions.
- Example games and programs including Hello World, Demo, Bench and Space
  Asteroids. See the [original project guide](../../README.md).
