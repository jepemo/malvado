# README media

`space-asteroids.gif` records the [Space Asteroids example](../../examples/space_asteroids/)
at source revision `8d9c781`. It uses scripted keyboard input with the existing
game logic and artwork. The clip contains only the game's rendered content.

The GIF loops an 8-second recording at 640 × 480. It uses a shared palette and
has no added visual effects. See [licenses and attribution](../development/licensing.md)
for the project's asset notices.
