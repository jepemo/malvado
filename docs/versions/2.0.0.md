# 2.0.0

Status: planned. The stable release distributes the engine validated in
[beta.1](2.0.0-beta.1.md).

## Release notes

- Malvado includes a shared process scheduler and 2D game APIs for C, Lua
  and experimental Rust.
- The SDK and CLI support project creation, checks and native game exports.
  The stable desktop targets are macOS arm64 and Linux x86_64. Windows x64
  and Android arm64 retain beta platform support.
- The SDK archives, source archive and versioned documentation identify
  the same source revision. Verify downloads with the supplied checksums.
