# Alpha.7 Rust sys SDK evidence

A7.2 is complete. Native Debug/Release SDK checks passed locally and in both
required host CI jobs. The safe Rust process API remains A7.3–A7.5 work.

## Delivered contract

- Rust 1.99.1 and the Clippy/rustfmt components are pinned through mise. CMake remains the native build owner;
  no C/Lua CMake target invokes or requires Cargo.
- `bindings/rust` contains one dependency-free crate, `malvado-sys`. Its surface
  covers the context, clock, cadence, native callbacks, process lifecycle,
  identity/owned handles, and resources needed by the scheduler proof.
- The installed SDK includes crate sources under `share/malvado/rust` without
  building Rust. An independent Cargo project can depend on these sources.
- `MALVADO_SDK_PREFIX` selects the installed CMake package. The core archive must
  resolve inside that prefix. No checkout fallback, source downloads, or implicit
  native engine build is allowed. CMake cache state is reset for package selection
  so replacing a prefix cannot silently retain the previous library.
- The native probe checks signatures and runs the ABI revision query before
  the release query. Both must match. Rust compares native field sizes,
  alignment, offsets, and enum values at compile time, also outside tests.
- The selected product is the existing static core plus libm. Dynamic-only
  packages are rejected. Dynamic loader validation is not applicable until a
  shared core product exists; future backend dependencies still require tests.
- Native macOS/Linux builds are supported by the implementation. Cross-target
  builds are rejected. Wrong native architecture fails the host compiler/linker
  or executable probe. No Windows/Android support is inferred.
- The development version is alpha.7, independent of milestone completion.
  Raw sys APIs remain unsafe. They do not yet supply async process ergonomics,
  resource RAII, graphics, or a player export workflow.

## Automated checks

`mise run test-rust` builds Debug and Release native SDKs with Cargo absent
from their build PATH. It installs each SDK, moves it to a path containing
spaces, and runs Cargo tests, clippy with warnings denied, and format checks.
The native signature probe and compile-time layout/value assertions run in
both profiles. Rust tests exercise invalid creation/advance calls, callback
activation, natural completion, exactly-once native cleanup, and an owned dead
handle after context destruction.

Negative SDK fixtures reject a missing prefix, nonexistent prefix, incomplete
package, incompatible ABI, incompatible release, changed field layout, changed
function signature, and dynamic-only package. The ABI mismatch fixture aborts
if the release query is called too early. Probe rebuilding avoids stale linker
output when an archive is replaced in place.

Finally, an offline external Cargo consumer links the relocated installed SDK
and depends on the installed crate sources. It uses no native checkout paths.

Local macOS checks passed in Debug and Release. The same `rust-sdk` task passed
on commit `926d1eefaf2e803acab8f394bfd818a40b170483` in
[Linux CI](https://github.com/jepemo/malvado/actions/runs/42781202107/job/129711409711)
and [macOS CI](https://github.com/jepemo/malvado/actions/runs/42781202107/job/129711409960).
These jobs cover both profiles, compile-time ABI checks, eight SDK rejection
fixtures, lint/format checks, and the installed offline external consumer. The full packaging, sanitizer, player and example matrix stays in A7.9.

The first Linux CI attempt exposed a minimal rustup profile without Clippy.
The mise configuration now explicitly requests Clippy and rustfmt, independent
of the runner profile. The failed attempt does not count as host acceptance.

Local native regressions passed: `mise run test-c` (48 tests) and
`mise run test-headless` (156 tests). A separate Lua headless configuration and
build with Cargo absent from PATH passed the scheduler and both C/Lua parity
tests (3 tests). C-only builds without Cargo are also part of `test-rust` on
both CI hosts. No Rust runtime change to Lua was required.
