# 2.0.0-alpha.8: complete API

Status: planned. Depends on the API inventory from alpha.6 and the Rust SDK in alpha.7. Graphics modes 7, 8, and 9 are planned for 2.1–2.3.

## Scope and planning gate

This version delivers API families and client behavior selected for 2.0 but not delivered in alpha.6 or alpha.7. It excludes graphics modes 7–9 and the GUI. Its implementation scope cannot be fixed until the alpha.6 inventory and alpha.7 contracts are available. Before implementation, list every remaining family and client command here, with explicit exclusions, contracts, and automated acceptance checks. Do not treat the placeholders below as individual finished features.

New API families must follow the [alpha.5 process and resource contracts](../api/process-inventory.md). Document and test any change to ownership, handle lifetime, or process queries as an API change.

## Inputs from the alpha.6 redesign

The unified loader, graph/animation descriptors, contextual world calls, main
camera, following and basic viewport/region/scroll integration belong to
alpha.6. Do not duplicate them as remaining alpha.8 families.

Alpha.6 records proposals for visible static world objects, focused text/font
API changes, advanced camera composition/follow options, and runtime ZIP
mounting. These are design candidates here, not approved implementation scope.
Select or exclude each in the inventory decision before adding a bounded
implementation item. The existing text/font capabilities remain available.
