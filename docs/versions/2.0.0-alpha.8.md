# 2.0.0-alpha.8

[Source tag](https://github.com/jepemo/malvado/tree/v2.0.0-alpha.8).

- Added Windows x64 MSVC authoring, SDK archives and standalone C, Lua and
  Rust player exports.
- Added Android arm64 APK and AAB export for all three languages from
  macOS and Linux, with emulator coverage for graphics, input, lifecycle
  and audio behavior.
- Established a shared platform validation workflow for macOS, Linux,
  Windows and Android.

## Accepted candidate

The [platform gate](https://github.com/jepemo/malvado/actions/runs/44280840065)
passed on `2a20b7ae9b8cc03a21a92bd2aee29e185789f6f1`. The three desktop SDK
archives passed checksum and notice checks. Fresh runners verified standalone
Windows players, and Android emulators exercised C, Lua and Rust packages.
See the [platform matrix](../development/platforms.md) for the tested
combinations and their limits.
