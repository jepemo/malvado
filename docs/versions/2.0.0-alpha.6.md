# 2.0.0-alpha.6: API inventory and assets

Status: planned. Depends on [alpha.3](2.0.0-alpha.3.md) and the API contracts.

## Scope and planning gate

This version selects the 2.0 API inventory and delivers scroll, regions, collision, one FPG variant, and one Aseprite subset. It does not deliver every API family; the remaining selected families belong to alpha.8. Graphics modes 7–9 and GUI work remain outside 2.0.

The exact API names, FPG variant, and Aseprite subset are not decided. The inventory and format decisions below must identify their inputs, exclusions, and acceptance tests. Split each selected capability into bounded implementation items before starting it. The version cannot close on an unbounded promise to support a format.

## Checklist

- [ ] Define the complete Malvado 2.0 API inventory, excluding modes 7, 8, and 9. Select Lua names and behavior for their value in 2.0. Malvado 1.0 compatibility is not a release gate and does not need a separate alpha. Assess historical asset formats separately.
- [ ] Include both Lua entry forms in the API inventory and preserve the shared startup contract from alpha.5.
- [ ] Specify and test process and API semantics against pinned references.
- [ ] Implement the selected scroll capability in C and Lua, with a contract, example, and automated graphics and parity checks.
- [ ] Implement the selected region capability in C and Lua, with a contract, example, and automated graphics and parity checks.
- [ ] Implement the selected collision capability in C and Lua, with a contract, example, and automated behavior and parity checks.
- [ ] Implement an importer for one pinned FPG variant with licensed fixtures.
- [ ] Implement a tested Aseprite PNG+JSON subset and report unsupported data.
- [ ] Preserve supported IDs, points, pixels, and palette data; document conversion limits.
- [ ] Give each delivered API symbol a contract, example, and semantic check. Finish remaining families in alpha.8.

See [compatibility](../api/compatibility.md) and [asset formats](../specs/assets.md).
