# Malvado 2.0.0-alpha.4 release notes

Draft for review. This file does not publish a release or create a tag. Complete the [alpha.4 checklist](2.0.0-alpha.4.md) and update the candidate details before publication.

Malvado 2 is in development. Its API, project format, and tools can change.

## Create a game

The SDK includes the `malvado` command, Lua runtime, and C libraries. Create a Lua game and run it:

```sh
malvado new my-game
cd my-game
malvado run
```

Use `malvado check` to check the syntax of Lua files without running them. Use `malvado doctor` to see the local client capabilities.

Create a C game with `malvado new --c my-c-game`. C projects need CMake and a C compiler. Use `malvado build` to build the game, or `malvado run` to build and start it.

## Export a game

On macOS and Linux, `malvado export` creates `dist/game` for the current host. The exported folder includes the runtime and license notices. It does not need an installed Malvado SDK or Lua interpreter on the player's computer.

On macOS, `malvado export --app` creates `dist/game.app`. Use `--id org.example.my-game` to set a bundle identifier for your game. The default identifier is shared by default exports. The initial app is not signed or notarized by Malvado.

See [SDK and projects](../site/sdk.md) for installation, project commands, and export details.

## Candidate and limitations

Before publication, record the tested source commit, CI run, archive names, SHA-256 checksums, and clean-host results here. Use the [desktop validation procedure](../development/alpha4-desktop-validation.md). Do not treat an untested development artifact as a release package.

- Initial desktop SDKs target macOS and Linux. Windows and Android work is planned for alpha.6. iOS is deferred.
- Exports target the current host. Cross-platform export is not available.
- `check` validates Lua syntax; it does not prove that assets, dependencies, or game logic work.
- A macOS app uses a default bundle identifier unless `--id` is supplied. Signing and notarization are not provided.
- Native Linux hardware, a separate clean macOS graphics host, and the remaining release checks must be verified before marking this alpha complete.
- The GUI and graphics modes 7, 8, and 9 are planned for later versions.
