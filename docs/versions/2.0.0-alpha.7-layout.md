# Alpha.7 shared binding layout evidence

The Lua adapter now lives in `bindings/lua/`, beside `bindings/rust/`. CMake
still owns Lua builds; Cargo owns Rust. The move preserves the native core,
public headers, runner, CLI, installed paths, target names, and API behavior.

The runtime's local globals include now resolves beside its source. The atomic
import test uses a private Lua binding include directory. CMake source lists,
the global inventory reader, CI static analysis, and current architecture
references use the new path. Earlier alpha evidence retains the old path as a
record of that revision. No active build or tool reference uses it.

Local checks passed: `mise run test` (156 tests), `mise run test-c` (48),
`mise run test-headless` (156), `mise run test-rust` (both profiles, lint, format,
ABI checks and installed consumer), and `mise run test-visual` (54). These
include API inventories, C/Lua parity, installed SDK consumers and package tests.
Host CI evidence is required before checking A7.11. C/Lua builds without Cargo
remain a required acceptance check. No runtime behavior was extracted or split.

`mise run test-headless-no-cargo` now repeats the complete Lua headless
configuration, build and 156 tests with Cargo absent from PATH. It passed
locally and replaces the ordinary headless command in both native host CI
jobs. `test-rust` continues to verify C-only native SDK builds without Cargo.
