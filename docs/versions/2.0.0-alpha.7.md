# 2.0.0-alpha.7

[Published prerelease](https://github.com/jepemo/malvado/releases/tag/v2.0.0-alpha.7)
from `6c56838`. All 15 [CI jobs](https://github.com/jepemo/malvado/actions/runs/43395529517)
passed on that revision.

- Added the Rust SDK with owned async processes, checked handles and native
  resource ownership over the shared C scheduler.
- Aligned C, Lua and Rust on native graphics, assets, animation, cameras,
  text, input, audio, collision and world movement.
- Added installed Rust project creation and native player exports. Verified
  relocated SDK consumers, ABI checks and runnable Rust guide snippets.
