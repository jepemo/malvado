# 2.0.0-alpha.7: Android and Windows

Status: planned. Depends on [alpha.4](2.0.0-alpha.4.md) and [alpha.6](2.0.0-alpha.6.md). Android and Windows do not block alphas 1–5.

## Scope

This version delivers Windows and Android support for the API and client selected in the preceding alphas. It includes automated Windows checks and Android emulator checks where supported. It does not include manual device or clean-machine checks; those are beta gates.

Use the [alpha.5 process and startup baseline](../api/process-inventory.md) for platform tests. Check context identity, process cleanup, and both entry forms in supported automated platform runs.

Before implementation, record the supported Windows and Android versions, architectures, toolchains, export forms, and emulator limits. Split the checks below by target and deliverable. A platform check closes only when its build, runtime behavior, packaging, and applicable automated tests pass.
