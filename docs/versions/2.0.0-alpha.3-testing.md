# Try alpha.3

Alpha.3 is in progress. These steps use the current `master` branch. They do not create a release or a tag.

## Build

From the repository root, install the tools and build the runtime:

```sh
mise install
mise run build
```

The first build downloads dependencies. See the [root README](../../README.md) for system packages and offline sources.

## Try the examples

Run each command from the repository root. Press **Escape** to close the window.

```sh
./build/malvado-run examples/helloworld/main.lua
./build/malvado-run examples/demo/main.lua
./build/malvado-run examples/space_asteroids/main.lua
./build/malvado-run examples/bench/main.lua
./build/malvado-run examples/audio/main.lua
./build/malvado-run examples/controllers/main.lua
```

- **Hello World:** check the greeting and Escape.
- **Demo:** use arrows and Enter or the mouse. Check the sprite, keyboard, text, and fade pages. Escape returns to the menu, then exits.
- **Space Asteroids:** use arrows to turn and move, Space to fire, and R to restart after a win or loss.
- **Benchmark:** hold Space to add processes. Watch the count and tick interval. This is not a separate CPU or render measurement.
- **Audio:** set a comfortable speaker volume first. Press 1 and 2 close together for overlapping effects. Use Space to start and stop the repeating tone.
- **Controller monitor:** connect and disconnect a controller. Check the slot, buttons, and stick values.

The [benchmark notes](../../benchmarks/README.md) give a separate headless measurement and its limits.

## Compare GUI prototypes

The prototypes use fixed sample data. They are not the editor.

```sh
mise run build-g0
./build-g0/gui-g0-raygui
./build-g0/gui-g0-imgui
```

Expand the tree, select a worker, resize each window, and compare the atlas region, focus, text, and DPI scale. See the [prototype notes](../../tools/gui-g0/README.md) for the differences and limits.

## Automated checks

```sh
mise run test
mise run test-headless
mise run test-c
mise run test-visual
mise run test-g0
```

Visual checks need a display or virtual display. Linux CI also checks keyboard and mouse events and uses a virtual audio device. It cannot confirm what you hear or how a physical controller behaves. See the [alpha.3 checklist](2.0.0-alpha.3.md) for pending work.
