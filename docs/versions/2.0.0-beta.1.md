# 2.0.0-beta.1

[Published prerelease](https://github.com/jepemo/malvado/releases/tag/v2.0.0-beta.1)
from `e96f4b191641bb4b29c8ab4d55ce191580c09158`.

## Release notes

- Documented the delivered C, Lua and experimental Rust APIs. Renamed the
  Rust entry point to `Game`.
- Added aligned startup, process and image lessons in C, Lua and Rust.
- Published macOS arm64, Linux x86_64 and Windows x64 SDKs, plus a verified
  source archive and versioned documentation. Check downloads against the
  supplied SHA-256 checksums.
- Windows x64 and Android arm64 have beta platform support. macOS and Linux
  can export C, Lua and Rust projects to Android arm64 APKs and AABs.
