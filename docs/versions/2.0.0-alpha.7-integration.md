# Alpha.7 native family acceptance

A7.6 accepts the delivered alpha.6 engine families through C, Lua and Rust.
The A7.1 [gap inventory](2.0.0-alpha.7-native-gaps.md) is the boundary. The older
partial notes in that inventory and the subchecks record implementation stages;
this audit resolves their remaining family and host-loop questions.

## Host integration decision

No new host-loop abstraction is needed. C and Rust explicitly advance the
context, commit input, execute planned ticks, maintain audio and draw. Lua's
runner owns that sequence for Lua games. This is a language hosting difference,
not a second scheduler or duplicated engine behavior. Shared rendering, text,
cameras, animation, clock accounting and stream refill use native operations.
Binding descriptor identity and playback roots remain language references.

C/Lua coexistence and native-only process rendering in Lua are tested. The safe
Rust engine owns its context; attaching it to an arbitrary existing Lua context
is not a delivered public API. Do not invent that contract to claim three-way
user-state conversion. Dynamic mixing and payload conversion remain excluded.
Lua aliases/legacy descriptors and language standard libraries do not require
parallel Rust API styles. See the [language matrix](../api/language-parity.md).

## Acceptance evidence

The final family audit ran these checks against the delivered implementation
with the [CI repairs](../development/alpha7-ci-repairs.md):

- macOS arm64: 68 native/Lua visual checks; Rust graphics-only compilation and
  combined-feature behavior, Clippy, format, signature/layout probes and offline
  installed consumers in Debug/Release; native Rust graphical ASan/UBSan.
- Ubuntu 24.04 arm64 in an isolated container: 83 Xvfb visual checks, including
  backend input injection; the same Rust Debug/Release graphics task with
  graphics-only compilation, combined behavior, Clippy/format, installed
  consumers, shared traces and keyboard/mouse/text injection.
- The unchanged C/Lua audio API and resource fixtures pass five consecutive
  runs with miniaudio's paced null device. The default SDK configuration retains
  platform audio. Automated evidence does not certify audible output.
- Core-only and Lua-without-Cargo regressions remain supported. The preceding
  implementation CI revision `5171fdf74a915a8701da9259d5d4d0e921d1d88a` passed
  the hosted C core, C assets, standard builds, Rust installed SDK jobs and
  documentation. Its failed graphics/package/analyzer paths are recorded and
  repaired separately; it is not a fully accepted final CI revision.

The local container checks use pinned dependency sources already verified by
CMake. They supplement hosted CI rather than replacing A7.9. A7.6 family
implementation and integration are accepted. Final exact-revision CI, candidate
packages and documentation closure remain A7.9/A7.10. No version tag or release
is implied. Windows/Android and physical-device acceptance keep their assigned
alpha.8/beta scope.
