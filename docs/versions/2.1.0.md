# 2.1.0: Windows and Android stabilization

Status: planned. Depends on [2.0.0](2.0.0.md). Windows x64 and Android
arm64 ship with beta platform support in 2.0. Use community reports and
manual validation to decide when each platform can move to stable support.

## Checklist

- [ ] Run the Windows x64 authoring walkthrough. Install, create C/Lua/Rust projects, run the lessons, use check/build/run/export, update the SDK and remove it. Verify that existing projects and exported games still work as applicable. Record the SDK revisions, Windows version, toolchain and results.
- [ ] Run C/Lua/Rust exports on a clean Windows x64 system. Check graphics, keyboard and mouse, physical controllers and hotplug, and audible sound and music. Record the system, driver and export profile.
- [ ] Run C/Lua/Rust packages from APKs and AABs on physical Android arm64 devices. Check touch coordinates and rotation, Back, Home and return, a connected keyboard, system IME composition and dismissal, and audible WAV/OGG before and after backgrounding. Record device models, OS versions, revisions and results.
- [ ] Review community reports for the beta platforms, resolve blockers and add regression tests for fixes. Run the affected manual checks and the full platform gate on the exact stabilization candidate. Update each platform's support status after its required checks pass.
