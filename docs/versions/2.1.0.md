# 2.1.0

Status: release candidate.

## Release notes

### Highlights

- Lua games gain optional handle methods, named asset directories,
  polyphonic sound voices, mouse and controller input edges, and window
  resizing. Globals and the `malvado` module share the same operations.
- The experimental Rust SDK adds a managed windowed runner, simpler process
  spawning and short runnable examples. Manual ticks remain available for
  headless games and hosts that own the loop.
- The SDK includes the CLI and runtime for C, Lua and Rust. macOS arm64 and
  Linux x86_64 are stable desktop targets. Windows x64 and Android arm64
  retain beta platform support.

### Upgrade from 2.0.0

- Lua games must update calls affected by the revised argument validation and
  option tables. Replace `fade_off(30)` with `fade_off(500)` to keep a
  half-second transition. Store the voice returned by `play_sound` and pass
  it to playback controls. See the [Lua API conventions](../api/lua-processes.md#lua-api-conventions),
  [drawing guide](../api/drawing.md), [fade guide](../api/fades.md) and
  [audio guide](../api/audio.md).
- Rust games must rebuild against the matching 2.1.0 SDK and crate sources.
  Update explicit spawn options and windowed startup using the
  [Rust migration guide](../development/rust-game-migration.md#migrate-spawning-and-windowed-code).
- Use `malvado new --lang c my-game` or `malvado new --lang rust my-game` to
  select a language. Lua remains the default.
