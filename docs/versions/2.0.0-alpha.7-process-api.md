# Alpha.7 safe Rust process API evidence

A7.4 is implemented and locally verified. The public `malvado` crate uses owned
Rust game state and the verified A7.3 adapter. A game struct can implement
`async fn run(self, ProcessContext) -> Result<(), Error>`. One spawn/future style
is supported; no macro crate or Lua alias surface was introduced.

Handles contain a native owned handle and full runtime/process identity.
Cloning keeps that identity; equal numeric IDs from different contexts are not
equal handles. Snapshots copy native type, priority, creator, owner and status.
Type/priority changes go to C. There is no duplicate native property storage,
mutable access to suspended Rust state, or raw context escape hatch.

Rust errors have named variants. An unexpected C result retains its numeric
code for diagnostics. Ended processes and closed contexts have explicit failure
behavior. Cross-context signaling rejects the foreign handle before touching
a context-local ID. Dead handles remain inspectable after context destruction.

The handle tests verify canonical current/spawn identity, initial state and
native mutation, stale/closed/foreign operations, invalid FPS failure cleanup,
and next-tick priority ordering. Compile-fail doctests reject moving an Engine
to a thread, a future borrowing caller-owned mutable data, use of moved game
state, and an attempt to tick through a process token.

The counter example compiles and runs to completion in both profiles, with a
bounded smoke check. The offline external consumer now uses the installed safe
crate and runs an async frame wait through the installed C SDK. It needs no
native source-tree paths. `mise run test-rust` passes the complete workspace
suite, compile-fail doctests, example smoke, clippy and formatting in Debug and
Release; Miri and native sanitizer evidence remain linked from the scheduler
proof. See the [process guide](../api/rust-processes.md) for runnable usage,
ownership, wake rules, error behavior, panic boundaries and limitations.

The complete lifecycle/resource stress matrix, genealogy queries and resource
release wrappers remain A7.5/A7.6 work. A7.8 still requires its graphical
examples and minigame; this minimal process example does not close that item.

The complete native host Rust jobs passed on Linux/macOS for commit `39b4569`;
see the [scheduler host evidence](2.0.0-alpha.7-scheduler.md#host-acceptance).
