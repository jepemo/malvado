Use [mise](https://mise.jdx.dev/configuration) as the project entry point for development tools and tasks. Keep CMake as the build system. Make setup, builds, tests, and examples consistent on macOS and Linux.

- [x] Add a project `mise.toml`. Pin the required development tools, including CMake and Python, to versions verified in CI. Document the compiler and platform system packages that mise does not provide.
