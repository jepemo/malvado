# 2.0.0-alpha.3: graphics and input

Status: scoped implementation and automated checks complete. The source tag is `v2.0.0-alpha.3`. Depends on [alpha.2](2.0.0-alpha.2.md). The mise tasks passed [CI for commit `f9b50e6`](https://github.com/jepemo/malvado/actions/runs/41024762521), including the Linux visual tests.

Use the [testing guide](2.0.0-alpha.3-testing.md) to try the current build and prototypes. The alpha.3 tag identifies the verified scope. It passed 55 standard tests and 80 tests in the visual configuration on macOS, and [CI](https://github.com/jepemo/malvado/actions/runs/41619288130).

The alpha.3 scope is the features and automated checks listed below. The full API inventory and remaining API families are planned for alpha.6 and alpha.8. Malvado 2.0 does not retain APIs only for 1.0 compatibility.

Manual user-flow, physical controller, and audible audio checks move to [beta.1](2.0.0-beta.1.md). Automated tests and unfinished implementation work remain in this alpha or their planned implementation milestone.

The [graphics modes 7, 8, and 9 proposal](../specs/graphics-modes.md) is planned for 2.1 through 2.3, after 2.0. It does not add implementation work or an exit gate to alpha.3.

PNG files, transformed image regions, and JSON atlas sprites are available in C and Lua. Schema 2 adds named animation frames and durations. See [images](../api/images.md) and the [schema 1 atlas CI run](https://github.com/jepemo/malvado/actions/runs/41026613918). Additional asset formats remain pending.

Keyboard held-state queries support letters, digits, arrows, and common control keys in C and Lua. Mouse position, held buttons, queued text input, and basic controller queries are also available. See the [input guide](../api/lua-processes.md). Linux CI tests [key presses and releases](https://github.com/jepemo/malvado/actions/runs/41027828358), [mouse movement and buttons](https://github.com/jepemo/malvado/actions/runs/41029239270), and [queued text input](https://github.com/jepemo/malvado/actions/runs/41030272187). Manual physical controller and hotplug tests move to beta.

WAV sound effects, independent sound instances, and WAV/OGG music streams are available in C and Lua. See [audio](../api/audio.md). [Linux CI](https://github.com/jepemo/malvado/actions/runs/41031056960) tests sound loading and playback with a virtual audio device. New audio behavior needs further verification.
