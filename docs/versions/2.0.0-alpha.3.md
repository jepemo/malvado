# 2.0.0-alpha.3: graphics and input

Status: in progress. Depends on [alpha.2](2.0.0-alpha.2.md). The mise tasks passed [CI for commit `f9b50e6`](https://github.com/jepemo/malvado/actions/runs/41024762521), including the Linux visual tests.

PNG files, transformed image regions, and schema 1 JSON atlas sprites are available in C and Lua. See [images](../api/images.md) and the [atlas CI run](https://github.com/jepemo/malvado/actions/runs/41026613918). Animation metadata and additional asset formats remain pending.

Keyboard held-state queries support letters, digits, arrows, and common control keys in C and Lua. Mouse position, held buttons, queued text input, and basic controller queries are also available. See the [input guide](../api/lua-processes.md). Linux CI tests [key presses and releases](https://github.com/jepemo/malvado/actions/runs/41027828358), [mouse movement and buttons](https://github.com/jepemo/malvado/actions/runs/41029239270), and [queued text input](https://github.com/jepemo/malvado/actions/runs/41030272187). Physical controller and hotplug tests remain pending.

WAV sound effects are available in C and Lua. See [audio](../api/audio.md). [Linux CI](https://github.com/jepemo/malvado/actions/runs/41031056960) tests sound loading and playback with a virtual audio device. Streaming, looping, and simultaneous instances remain pending.
