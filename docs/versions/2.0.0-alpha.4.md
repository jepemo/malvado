# 2.0.0-alpha.4

[Source tag](https://github.com/jepemo/malvado/tree/v2.0.0-alpha.4).

- Added the CLI for creating, checking, building, running and exporting

- Verified SDK consumers and exports on fresh runners. See the [CLI
