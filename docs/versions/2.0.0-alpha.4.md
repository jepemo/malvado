# 2.0.0-alpha.4: CLI and desktop SDK

Status: in progress. Builds on the tagged [alpha.3 preview](2.0.0-alpha.3.md); its unchecked verification items remain open.

## Checklist

- [ ] Decide the single user-facing `malvado` command and its `run`, `new`, and optional GUI entry points. See the [CLI proposal](../specs/cli.md#command-name-under-review).
  - [x] Add an initial `malvado new PATH` and `malvado run [FILE]` executable. `run --headless` supports automated checks. Project metadata, export, and GUI commands remain pending.
  - [x] Check project creation, paths with spaces, refusal to overwrite, and headless execution with CTest.
  - [x] Open the generated Lua game in a graphics test on macOS. Linux CI verification remains pending.
  - [x] Add `malvado check [FILE]` to check Lua source syntax without executing it. With no file, it checks the current project directory recursively. Full project, dependency, and asset validation remains pending.
  - [x] Install the C core and optional atlas parser as `Malvado::core` and `Malvado::assets`. Test independent consumers without Lua or raylib. Graphics and full SDK packaging remain pending.
- [ ] Provide the C SDK, Lua runner, templates, and desktop packages for macOS/Linux.
- [ ] Implement `malvado-cli` project creation, run, check, doctor, and desktop export.
- [ ] Create, run, export, and execute one C game and one Lua game on clean macOS/Linux hosts.
- [ ] Verify package contents, dependencies, notices, and checksums.
- [ ] Document SDK installation, CLI commands, and export workflows.
- [ ] Prepare a release candidate and draft release after package tests pass.
- [ ] Keep project and export services usable by a future GUI. GUI implementation belongs to 2.4.

Windows validation and Android export are in [alpha.6](2.0.0-alpha.6.md). See [CLI](../specs/cli.md), [GUI](../specs/gui.md), and [distribution](../development/distribution.md).

The optional [graphics modes proposal](../specs/graphics-modes.md) can inform future SDK interfaces. Its modes are planned for 2.1 through 2.3 and is not an alpha.4 release gate.
