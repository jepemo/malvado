# 2.0.0-alpha.4: CLI and desktop SDK

Status: in progress. Builds on the tagged [alpha.3 preview](2.0.0-alpha.3.md); its unchecked verification items remain open.

Automated SDK and export checks remain in alpha.4. Manual end-to-end tests on clean computers and physical hardware move to [beta.1](2.0.0-beta.1.md). Their absence does not block this alpha.
