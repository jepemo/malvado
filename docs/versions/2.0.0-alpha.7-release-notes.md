# Malvado 2.0.0-alpha.7

First-class C, Lua and Rust APIs over one native process scheduler.

## What changed

- Added the safe Rust API with owned async processes, checked handles, cancellation and native resource ownership.
- Completed shared native graphics, images/atlases/FPG, animation, cameras, text/fonts, input, audio, collisions and world movement.
- Added installed Rust projects with `malvado new --lang rust`, `check`, `build`, `run` and native player exports. Lua and C projects remain supported.
- Verified installed and relocated SDKs, independent players, native ABI/version checks, all 37 Rust guide snippets and current documentation links.

## Downloads

Choose the SDK for your host. These are Debug development SDKs, with the CLI,
Lua runtime, static C libraries, public headers, CMake package, Rust crate sources
and dependency license notices.

| Host | SDK |
| --- | --- |
| macOS Apple Silicon (arm64) | `malvado-sdk-2.0.0-alpha.7-darwin-arm64.tar.gz` |
| Linux x86_64 | `malvado-sdk-2.0.0-alpha.7-linux-x86_64.tar.gz` |

Download the matching `.sha256` file too. Before extraction, use
`shasum -a 256 -c <archive>.sha256` on macOS or `sha256sum -c <archive>.sha256`
on Linux. Extract into an empty directory and add its `bin` directory to PATH.

For Rust authoring, install Cargo/rustc (the project pins Rust 1.99.1), CMake and
a C compiler. Then run:

```sh
malvado doctor
malvado new --lang rust my-game
cd my-game
malvado check
malvado run
malvado export
```

Use `malvado new my-game` for Lua or `malvado new --c my-game` for C. Player
exports do not need the SDK or authoring tools. Rust checks can execute Cargo
build scripts and procedural macros; they do not start the game.

## Verification and scope

Source commit: `6c56838ad1562cd5015a072a813c9c9d21856590`.
[All 15 CI jobs passed](https://github.com/jepemo/malvado/actions/runs/43395529517).
The attached SDKs are the exact artifacts tested and collected by that run;
they were not rebuilt for this publication.

This is an alpha prerelease. APIs and tools can change, and Malvado 2 is not
backward compatible with Malvado 1. No permanent 2.x API/ABI freeze is promised.

- Windows/Android validation follows in alpha.8. Cross-compilation is not provided.
- Physical-device, audible-output and complete manual user-flow checks remain beta work.
- macOS app exports are not signed or notarized by Malvado.
- Public dynamic language mixing and automatic packaging of third-party game dependency runtimes are not provided.
