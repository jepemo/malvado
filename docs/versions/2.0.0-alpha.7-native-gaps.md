# Alpha.7 native boundary decisions

This completes the A7.1 review of the delivered alpha.6 surface. It specifies
work inside A7.6, not new available APIs. Public signatures will be added with
their implementation and C/Lua tests. The [baseline](2.0.0-alpha.7-baseline.md)
links the complete existing function, type and constant maps.

Current family acceptance and the host-loop boundary are recorded in the
[integration audit](2.0.0-alpha.7-integration.md). The sections below preserve
the A7.1 inventory and subsequent implementation evidence.

## Original operations that depended on Lua state

The compositions below were identified in `bindings/lua/runtime.c` during
the A7.1 review. Delivered portions are recorded below; the remaining contracts
stay in A7.6. Keep Lua
argument conversion, aliases and registry references there. Move shared engine
behavior to C only when implementing the corresponding native service. Do not
export Lua values, registry indices, or the binding's `Engine` singleton.

| Operation and current entry point | Required native contract | Required regression evidence in A7.6 |
| --- | --- | --- |
| Read/write process x, y, z, angle, size and graph; `self_index`, `self_newindex` | Context-bound live identity; one authoritative native property record. Getters copy values. Failed validation leaves state unchanged. Preserve existing Lua assignment and invalid-render behavior. | Defaults, stale/foreign identities, mutation between ticks, C/Lua/Rust transforms. |
| Create rect/circle descriptors; `graphic_create` | Immutable copied geometry and color, explicit pivot, no backend dependency. Reject invalid dimensions and unsupported pivots. | Boundary dimensions, invalid options, headless geometry and rendering. |
| Select image/atlas/FPG graph; `graph_select`, `graphic_sprite` | A selected graph retains its image/metadata until all owners and queued uses release it. No duplicate native image ownership. Failed lookup leaves assignment unchanged. | Missing IDs/names, pivots, library identity, cleanup and installed consumer. |
| Load unified asset; `load_asset` | Explicit context and path. Dispatch and indexing must use shared native loaders. Output ownership transfers only on success; partial failure releases temporary objects. | PNG/JSON/Aseprite/FPG fixtures, headless metadata, bad files and cleanup. |
| Select/play automatic animation; `animation_select`, `sync_process_collider` | Immutable sequence plus per-process native playback state. Advance from native simulation ticks; graphics and collider sample the same frame. | Pause/freeze/sleep, finite and infinite repeats, delta and render-frequency parity. |
| Collect process graph and immediate draws; process draw references | Draw commands retain referenced resources. Stable z/creation order; graph before that process's commands. Sleeping hides and frozen stays visible. | Draw order, removal during tick, region/scroll, shutdown and sanitizer runs. |
| Set draw color/background and queue fades; `set_color`, `clear_screen`, `queue_fade` | Runner-scoped state, explicit bounded queue (16 pending transitions), same native fade math. Invalid channels/durations and queue overflow preserve prior work. | Queue limits, transition order, alpha composition and headless state. |
| Persistent text; `write_text`, `change_text`, `delete_text` | Context/process-owned text retains its font. Replacement validates before mutation; deletion releases once. No device access after platform shutdown. | Owner termination, font replacement, stale text and graphics captures. |
| Managed image/font and audio load/clone; `load_image`, `load_font`, `load_sound`, `clone_sound`, `load_music` | Register caller-owned platform data with the native resource manager exactly once. Failure keeps caller ownership. Retained references do not extend platform lifetime. | Load failures, owner teardown, clone independence and sanitizer runs. |
| Playback retention and stream update; sound/music action wrappers | Playing or paused objects keep required native data alive. Stop/completion releases playback retention once. Device closes after outstanding playback work. | Play/pause/resume/stop, owner death and shutdown. |
| Camera main/explicit selection and destroy; `camera_create`, `process_camera`, `camera_destroy` | Runner owns main camera; explicit cameras have checked live identity. Process selection retains identity; closed cameras hide graphics until reassignment. Projection uses existing C math. | Main/screen/explicit selection, idempotent close, viewport/scroll composition. |
| Follow target; `camera_follow`, `update_cameras` | Store a checked process reference. Update at end of native tick after removals; ending target clears follow and preserves final camera position. | Attached child death, foreign/dead target, tick/render-frequency and viewport parity. |
| Derive/synchronize collider; `process_collider`, `sync_process_collider` | Explicit collider overrides selected graph. Native visual properties supply transforms. Clear stale geometry when unsupported; retain existing type and query order. | Headless graph override, invalid geometry, foreign context and render-frequency parity. |
| World process collision/move; `world_process_collision`, `world_process_move`, `world_move` | Native world math remains authoritative. Derive the shape from native process properties and apply the resulting x/y atomically. Missing world or dead process fails without mutation. | Fast motion, corner slide, absent world, collider resync and shared platform fixture. |

No new C scheduler hook is needed for the first Rust proof: `mv_process_spawn`
and `mv_process_spawn_related` already transfer user data on success and call
the destructor once at native removal. Natural return, self-kill, external kill,
recursive tick rejection and shutdown must be measured before changing these
hooks. Safe Rust must prevent context destruction while callbacks are active.

## Inventory coverage and architecture outcome

The existing process, asset, platform, input, audio and collision maps cover
all current public C declarations and enum values through their automated map
checks. Animation and camera native values are covered by their contracts and
installed SDK examples. Lua global and namespace inventory tests cover aliases;
these aliases do not become extra Rust APIs. The table above covers the
binding-managed compositions that those symbol maps alone cannot certify.
`legacy_fpg` and `malvado.legacy` remain Lua adapters; external format readers
are separate native capabilities, not a Rust legacy gameplay style.

CMake owns the installed SDK; Cargo will link it through an explicit prefix.
Start with the existing static core archive on native macOS/Linux hosts. There
is no dynamic core product today. Reject dynamic-only SDKs rather than guessing
link flags; adding shared-core distribution requires a separate tested build
configuration in A7.2/A7.9. Do not auto-build or download C sources from Cargo.
The sys crate declares only the surface its consumers use and checks every such
declaration against installed C headers. Additional declarations require the
same check. A7.6 still covers every alpha.6 family above.

Mixed-language payload conversion and public dynamic mixing remain outside
this milestone. Internal mixed C/Lua tests remain useful evidence for the one
scheduler and native identity contract. No global source-tree reorganization,
new dependencies, or public macros are needed for this boundary.

## Trace baseline

`alpha7_baseline_parity` compares C and Lua output with a fixed golden trace.
It checks first activation at tick 1, a detached child first running at tick 2,
locals preserved across frame waits, 15 FPS activations at ticks 1/5/9, and
three exactly-once cleanups. Native cadence is used by both implementations.

The existing `c_lua_parity` checks message transfer, freeze/wakeup ordering and
kill cleanup against a fixed trace. The headless suite also checks every integer
cadence from 0 to 60, native process ordering, recursive ticks, natural cascades,
creation versus ownership trees, and mixed native/Lua contexts. Together these
are the A7.1 baseline, not proof of future Rust lifetime safety.

## Delivered fade boundary

A7.6n/o move the bounded fade FIFO and full-window overlay to the native
platform service. Lua keeps argument conversion and one runner-owned queue;
Rust uses copied native queues and explicit frame drawing. Tick advancement
stays explicit in native C/Rust hosts and at the existing Lua end-of-tick point.
No rendering call advances a fade. Invalid or full enqueue operations preserve
all work. Overlay drawing rejects active clip/scroll scopes without changing
state. This closes the fade portion of the runner-state row. Draw color and
background ownership remain open. See the [fade contract](../api/fades.md).

## Delivered simple-graphic boundary

A7.6p/q move rectangle/circle bounds and pivot construction into the core.
A7.6r/s move primitive graph scale/pivot drawing into the native backend. Lua
keeps its immutable graphic userdata and argument conversion; Rust draws copied
Geometry values through the same native operation. Explicit Rust collider
conversion uses the same local shape. Primitive stored color/assignment and native visual properties are delivered
below. Asset graph selection and automatic native collider synchronization
remain open. See the [geometry and drawing contract](../api/graphic-geometry.md).

## Delivered drawing defaults

A7.6t/u move the runner's drawing color/background defaults and channel
validation into a native copied state. Lua keeps one initialized value per
runner and captures colors in the existing process command queue. Rust uses
explicit values as frame and draw arguments. Together with the delivered fade
queue/overlay, this closes the color/background/fade state row above. Process
draw collection and persistent text remain open. See the
[drawing defaults contract](../api/draw-state.md).

## Delivered process depth and order

A7.6v/w move finite process z and visible ordering into the core. Lua preserves
numeric presentation only; it reads native depth and renders the native ordered
snapshot. Rust exposes depth through owned handles and a copied visible-order
query. Priority, sleep/freeze semantics and graph-before-command order remain
unchanged. Position/angle/size are completed below; graph storage and draw-command
ownership remain open. See the [visual order contract](../api/process-visual-order.md).

## Delivered native position storage

A7.6x/y add atomic finite native x/y storage and safe Rust handle access.
Installed-header checks cover both signatures. This is the storage part of the
visual-property row only. A7.6z connects valid Lua numeric position, world
movement, graph rendering,
camera follow and derived collider queries to this storage. Lua invalid visual
overrides remain local and preserve existing error behavior. A7.6aa also
connects native angle/scale with Lua and Rust. Graph storage and automatic Rust
drawing remain open. See the
[position storage contract](../api/process-visual-order.md#native-position-storage).

## Delivered process rotation and scale

A7.6aa closes finite native angle/scale storage and the C/Lua/Rust access path.
Lua graph drawing and derived collider/world operations use native values;
invalid Lua visual overrides retain their previous behavior. Direct C/Rust
collider transforms remain explicit. This closes the x/y/z/angle/size part of
the first inventory row. Selected graph storage, image retention, automatic
animation integration and process draw-command ownership remain in A7.6.

## Delivered contextual world operations

A7.6ab moves native process/world queries and atomic x/y writeback into the C
core. Lua supplies selected geometry and uses this service for native numeric
properties. Hypothetical positions and local invalid visual overrides retain
the existing lower-level native geometry path. Graph selection and derived
collider registration remain Lua responsibilities until native graph storage
is delivered. A7.6ac exposes the same operations through safe Rust `World::query_process`
and `World::move_process`, with explicit optional geometry and checked handles.
No second movement algorithm or scheduler is introduced. See the
[process/world contract](../api/collision.md#contextual-process-movement).

## Delivered native follow update

A7.6ad moves target position lookup, checked identity, dead-target clearing and
camera centering into one native follow step. Lua calls it at its existing
end-of-tick point and keeps only binding-owned invalid-visual checks and target
userdata references. A7.6ae adds safe Rust Follow state with explicit update
and clear operations and the same native identity/lifetime contract. This
closes the follow-update row, including target death
without retaining processes/resources. Main/explicit camera ownership, close
identity and process selection still require the native camera service. See the
[follow contract](../api/cameras.md#native-process-follow-update).

## Delivered primitive process graphs

A7.6af stores copied canonical rectangle/circle geometry and color in the native
process. Lua primitive assignment/readback, rendering and derived collider
queries share that descriptor. The native explicit drawing pass uses core
z/creation order and the existing primitive backend, including sleep/freeze
visibility and clip/scroll scopes. This closes primitive graph storage/color
and native primitive drawing. Image/sprite/animation graph retention, generic
process command ownership and automatic native collider selection remain open.
See the [primitive process contract](../api/graphic-geometry.md#primitive-process-graphs).

A7.6ag adds copied safe Rust Graphic assignment/readback and a frame-bound
process primitive pass through the same native operation. Graphic/Color values
are available without graphics dependencies. This closes safe Rust primitive
process drawing, including native visual ordering, sleep/freeze and clear.
Asset graph retention, automatic collider selection, camera assignment and
per-process immediate-command collection remain open.

## Delivered bound primitive colliders

A7.6ah closes native primitive graph collider selection and synchronization.
New processes select their primitive graph by default. A copied local override
can replace it while following native visual properties; clear disables, and
the existing set operation retains an independent fixed transform. C queries
refresh bounds without any Lua tick or draw. Lua primitive/local numeric paths
use the same binding operation while preserving invalid-visual and asset paths.
This revises the earlier alpha.7 primitive default and preserves fixed explicit
registrations. Asset graph-derived geometry and automatic world shape selection
remain separate work. See the [bound contract](../api/collision.md#bound-process-colliders).

A7.6ai adds safe Rust local binding and default primitive collider behavior,
using the same native query path. Its golden trace matches C/Lua and its tests
cover fixed-mode preservation, invalid-source recovery, local offset rotation
and dead/closed handles. This closes primitive collider synchronization across
all three APIs. Images/sprites/animations and automatic world shape selection
remain in A7.6.

## Delivered selected world geometry

A7.6aj closes native world query/movement selection over primitive graphs,
bound local overrides, fixed registrations and disabled/absent geometry. Fixed
movement translates both origins by the permitted displacement and commits
atomically. Lua numeric world/process paths use the same selection service;
hypothetical queries and binding-specific invalid values keep their established
path. Asset graph storage and ownership remain open, but world selection now
consumes the already selected geometry without a caller-supplied shape. See the
[selected world contract](../api/collision.md#world-operations-with-selected-geometry).

A7.6ak adds safe Rust selected query/movement over borrowed handles and worlds.
The C/Lua/Rust world trace, selected-mode and fixed-offset tests, installed
consumer and bounded SDK sample verify the same core operation. This closes
selected world geometry across all three APIs. Native asset graph ownership,
automatic animation, camera selection, persistent text and process command
collection remain in A7.6.

## Delivered camera identity and selection

A7.6al closes native context-owned main/explicit camera values, checked identity,
close semantics and process main/screen/explicit selection. Lua uses the same
values and selection, preserving owned userdata cleanup and borrowed native

[the identity contract](../api/cameras.md#context-owned-camera-identities-and-selection).

A7.6am delivers safe Rust CameraHandle, native process selection/resolution and
registered Follow updates. Context ownership, clone/snapshot behavior, explicit
close and thread/foreign/closed errors are documented and verified, including
core-only and graphical installed consumers. Camera identity/selection is now
shared across C/Lua/Rust. Asset graph lifetimes, process commands and native
region/scroll descriptors, persistent text and shared platform resource
registration remain open in A7.6.

## Delivered process region and local scroll

A7.6an stores copied optional regions and bounded local scroll in C. Lua
assignment/readback, graph drawing and command scopes use the same values.
Native primitive drawing composes process/camera/host clipping and scroll,
including frozen processes. Pure core helpers expose the effective clip and
projection offset without a window or tick. Descriptor changes do not move

Asset graph lifetimes, process command collection, persistent text and shared
platform resource registration remain open in A7.6.

A7.6ao adds safe Rust handle access and pure-core view composition over the same
native service. Regions are copied values; scroll affects drawing only. Native
process rendering applies the descriptors and restores host scopes. This closes
process region/scroll across C/Lua/Rust; the remaining A7.6 work above stays open.

## Delivered managed platform adoption

A7.6ap moves image, font, sound and music destructor registration into typed
native constructors over the existing resource manager. Lua loads and sound
clones use the constructors; a failed adoption leaves cleanup with the caller.
C and unsafe Rust share the same transfer/error contract. Safe Rust already
uses the native owner/retain/transfer manager with owned platform values that
retain their devices. See [managed platform resources](../api/managed-platform-resources.md).
This closes native platform load/clone registration. Playback maintenance and
retention remain explicit in the existing language hosts; shared runner audio
maintenance, asset graph lifetimes, automatic animation, process commands and
persistent text remain in A7.6.

A7.6aq also moves atlas metadata registration into the native assets service.
Lua atlas/Aseprite and unified-asset metadata loads share its destructor and
owner/retain/transfer contract. The SDK exports the assets-to-core dependency;
metadata remains independent of graphics and retains no image. C and Rust
fixtures read retained sprites after context shutdown. See [managed atlas
metadata](../api/managed-atlases.md). Unified load dispatch, selected asset graph
ownership and automatic playback remain separate open work.

A7.6ap/aq macOS batch evidence: C-only (65), C-assets (73), standard/headless
(186 each) and visual (61) pass. Rust core/assets/graphics Debug and Release,
relocated installed consumers and signature probes, Clippy/format and native
graphical ASan/UBSan pass. Rust itself is not sanitizer-instrumented; macOS leak
detection is disabled. Two graphics attempts failed during window creation
while all monitors were asleep; isolated window/resource checks and the complete
rerun passed with the display kept awake. Linux CI and final release acceptance
are not certified by these local checks.

GC guards before metadata ownership moves into existing wrappers. Source and
metadata lifetimes are independent; texture creation and actual-image bounds
validation remain explicit. Every allocation failure path in each metadata
family is injected and checked for cleanup. See [the metadata contract](../api/asset-library-metadata.md).
This closes unified library metadata construction. Native visual resource
construction/indexing, selected asset graph ownership, automatic playback,
process commands, persistent text and shared audio maintenance remain in A7.6.

A7.6au adds safe Rust Library and Metadata values over the same native dispatcher.
Opening consumes an owned source, serializes JSON parsing and moves validated
pointers into the existing Atlas/Fpg/Manifest wrappers. Metadata can outlive its
source, file and Resource context. The installed consumer uses every Library
method; no Rust format parser or second ownership manager is introduced.

## Delivered shared scene rendering

## Delivered shared audio maintenance

A7.6cn–A7.6cp move pause state and stream refill into the native platform.
Lua and Rust query that state for playback retention. Lua services the device
on host iterations, including paused/no-tick frames; Rust exposes explicit
Audio::update over the same pass. The native stream index is borrowed and
unlinked on destroy. C instance destruction and device ownership are unchanged.

Binding playback roots remain Lua registry references or Rust Rc values. They
keep language-owned playback data alive and use the existing native resource
manager for process/context ownership. They are not a second engine scheduler
or a separate source of audio control state. The [maintenance contract](../api/audio-maintenance.md)
records this boundary and the automated native/Lua/Rust evidence. This closes the
shared pause/refill portion of the older pending notes above. The final runner
integration and parity audit is accepted in the
[integration evidence](2.0.0-alpha.7-integration.md).
