# Alpha.7 native boundary decisions

This completes the A7.1 review of the delivered alpha.6 surface. It specifies
work inside A7.6, not new available APIs. Public signatures will be added with
their implementation and C/Lua tests. The [baseline](2.0.0-alpha.7-baseline.md)
links the complete existing function, type and constant maps.

## Operations that still depend on Lua state

The compositions below were identified in `bindings/lua/runtime.c` during
the A7.1 review. Delivered portions are recorded below; the remaining contracts
stay in A7.6. Keep Lua
argument conversion, aliases and registry references there. Move shared engine
behavior to C only when implementing the corresponding native service. Do not
export Lua values, registry indices, or the binding's `Engine` singleton.

| Operation and current entry point | Required native contract | Required regression evidence in A7.6 |
| --- | --- | --- |
| Read/write process x, y, z, angle, size and graph; `self_index`, `self_newindex` | Context-bound live identity; one authoritative native property record. Getters copy values. Failed validation leaves state unchanged. Preserve existing Lua assignment and invalid-render behavior. | Defaults, stale/foreign identities, mutation between ticks, C/Lua/Rust transforms. |
| Create rect/circle descriptors; `graphic_create` | Immutable copied geometry and color, explicit pivot, no backend dependency. Reject invalid dimensions and unsupported pivots. | Boundary dimensions, invalid options, headless geometry and rendering. |
| Select image/atlas/FPG graph; `graph_select`, `graphic_sprite` | A selected graph retains its image/metadata until all owners and queued uses release it. No duplicate native image ownership. Failed lookup leaves assignment unchanged. | Missing IDs/names, pivots, library identity, cleanup and installed consumer. |
| Load unified asset; `load_asset` | Explicit context and path. Dispatch and indexing must use shared native loaders. Output ownership transfers only on success; partial failure releases temporary objects. | PNG/JSON/Aseprite/FPG fixtures, headless metadata, bad files and cleanup. |
| Select/play automatic animation; `animation_select`, `sync_process_collider` | Immutable sequence plus per-process native playback state. Advance from native simulation ticks; graphics and collider sample the same frame. | Pause/freeze/sleep, finite and infinite repeats, delta and render-frequency parity. |
| Collect process graph and immediate draws; process draw references | Draw commands retain referenced resources. Stable z/creation order; graph before that process's commands. Sleeping hides and frozen stays visible. | Draw order, removal during tick, region/scroll, shutdown and sanitizer runs. |
| Set draw color/background and queue fades; `set_color`, `clear_screen`, `queue_fade` | Runner-scoped state, explicit bounded queue (16 pending transitions), same native fade math. Invalid channels/durations and queue overflow preserve prior work. | Queue limits, transition order, alpha composition and headless state. |
| Persistent text; `write_text`, `change_text`, `delete_text` | Context/process-owned text retains its font. Replacement validates before mutation; deletion releases once. No device access after platform shutdown. | Owner termination, font replacement, stale text and graphics captures. |
| Managed image/font and audio load/clone; `load_image`, `load_font`, `load_sound`, `clone_sound`, `load_music` | Register caller-owned platform data with the native resource manager exactly once. Failure keeps caller ownership. Retained references do not extend platform lifetime. | Load failures, owner teardown, clone independence and sanitizer runs. |
| Playback retention and stream update; sound/music action wrappers | Playing or paused objects keep required native data alive. Stop/completion releases playback retention once. Device closes after outstanding playback work. | Play/pause/resume/stop, owner death and shutdown. |
| Camera main/explicit selection and destroy; `camera_create`, `process_camera`, `camera_destroy` | Runner owns main camera; explicit cameras have checked live identity. Process selection retains identity; closed cameras hide graphics until reassignment. Projection uses existing C math. | Main/screen/explicit selection, idempotent close, viewport/scroll composition. |
| Follow target; `camera_follow`, `update_cameras` | Store a checked process reference. Update at end of native tick after removals; ending target clears follow and preserves final camera position. | Attached child death, foreign/dead target, tick/render-frequency and viewport parity. |
| Derive/synchronize collider; `process_collider`, `sync_process_collider` | Explicit collider overrides selected graph. Native visual properties supply transforms. Clear stale geometry when unsupported; retain existing type and query order. | Headless graph override, invalid geometry, foreign context and render-frequency parity. |
| World process collision/move; `world_process_collision`, `world_process_move`, `world_move` | Native world math remains authoritative. Derive the shape from native process properties and apply the resulting x/y atomically. Missing world or dead process fails without mutation. | Fast motion, corner slide, absent world, collider resync and shared platform fixture. |

No new C scheduler hook is needed for the first Rust proof: `mv_process_spawn`
and `mv_process_spawn_related` already transfer user data on success and call
the destructor once at native removal. Natural return, self-kill, external kill,
recursive tick rejection and shutdown must be measured before changing these
hooks. Safe Rust must prevent context destruction while callbacks are active.

## Inventory coverage and architecture outcome

The existing process, asset, platform, input, audio and collision maps cover
all current public C declarations and enum values through their automated map
checks. Animation and camera native values are covered by their contracts and
installed SDK examples. Lua global and namespace inventory tests cover aliases;
these aliases do not become extra Rust APIs. The table above covers the
binding-managed compositions that those symbol maps alone cannot certify.
`legacy_fpg` and `malvado.legacy` remain Lua adapters; external format readers
are separate native capabilities, not a Rust legacy gameplay style.

CMake owns the installed SDK; Cargo will link it through an explicit prefix.
Start with the existing static core archive on native macOS/Linux hosts. There
is no dynamic core product today. Reject dynamic-only SDKs rather than guessing
link flags; adding shared-core distribution requires a separate tested build
configuration in A7.2/A7.9. Do not auto-build or download C sources from Cargo.
The sys crate declares only the surface its consumers use and checks every such
declaration against installed C headers. Additional declarations require the
same check. A7.6 still covers every alpha.6 family above.

Mixed-language payload conversion and public dynamic mixing remain outside
this milestone. Internal mixed C/Lua tests remain useful evidence for the one
scheduler and native identity contract. No global source-tree reorganization,
new dependencies, or public macros are needed for this boundary.

## Trace baseline

`alpha7_baseline_parity` compares C and Lua output with a fixed golden trace.
It checks first activation at tick 1, a detached child first running at tick 2,
locals preserved across frame waits, 15 FPS activations at ticks 1/5/9, and
three exactly-once cleanups. Native cadence is used by both implementations.

The existing `c_lua_parity` checks message transfer, freeze/wakeup ordering and
kill cleanup against a fixed trace. The headless suite also checks every integer
cadence from 0 to 60, native process ordering, recursive ticks, natural cascades,
creation versus ownership trees, and mixed native/Lua contexts. Together these
are the A7.1 baseline, not proof of future Rust lifetime safety.

## Delivered fade boundary

A7.6n/o move the bounded fade FIFO and full-window overlay to the native
platform service. Lua keeps argument conversion and one runner-owned queue;
Rust uses copied native queues and explicit frame drawing. Tick advancement
stays explicit in native C/Rust hosts and at the existing Lua end-of-tick point.
No rendering call advances a fade. Invalid or full enqueue operations preserve
all work. Overlay drawing rejects active clip/scroll scopes without changing
state. This closes the fade portion of the runner-state row. Draw color and
background ownership remain open. See the [fade contract](../api/fades.md).
