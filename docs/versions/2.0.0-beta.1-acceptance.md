# Beta.1 first candidate verification

The first tested candidate is `0f3633b9495654948c0f43167217887da0e06493`.
The three workflows passed all 23 jobs on that exact revision.

| Workflow | Scope | Result |
| --- | --- | --- |
| [CI](https://github.com/jepemo/malvado/actions/runs/44316829453) | macOS arm64 and Ubuntu x86_64, C/Lua/Rust, SDK consumers, source archive, sanitizers and Linux graphics | 16 jobs passed |
| [Windows](https://github.com/jepemo/malvado/actions/runs/44316829580) | x64 MSVC, Debug and Release SDKs, C/Lua/Rust and clean exported players | 3 jobs passed |
| [Android](https://github.com/jepemo/malvado/actions/runs/44316829439) | API 34 x86_64 fixtures and translated arm64 player packages, Debug and Release | 4 jobs passed |

The [platform matrix](../development/alpha8-platforms.md) defines the same
host, target and toolchain limits. macOS and Linux native SDKs support
desktop exports and Android arm64 authoring. Windows exports native x64
games. The x86_64 Android fixtures exercise the engine in the emulator.
The supported production Android artifact target is arm64.

The downloaded production Android reports cover 24 C, Lua and Rust APK
launches, including APKs derived from Release AABs, plus eight IME and two
audio-focus launches. All 34 package IDs were distinct and each result
recorded cleanup. The reports record nine rejected invalid native builds.
The Linux graphics job ran all nine teaching lesson variants and sampled the
exported PNG pixels for each language.
