# Alpha.7 native Rust collision SDK progress

The explicit native collision/world layer is implemented. A7.6 remains open.
This page records completed code and verification inside that larger gate; it
does not replace its remaining graphics, platform, or shared visual contracts.

The sys crate declares all functions and types in `malvado/collision.h` and
checks signatures, record layouts and kind constants against the installed C
headers. The safe layer supplies immutable Shape, copied Rect/Transform/Sweep,
owned owner-thread World, and native process collider operations. Native C math,
resource ownership, process identity, errors and query order remain authoritative.
Rust does not introduce broad-phase tests, sweep math, contact correction, or
another scheduler. World insertion retains the native combined failure meaning.

Nine tests verify constructor/geometry errors, transforms and offsets, tangency,
fast circle and rotated-rectangle motion, corner contact, nonoverlap after move,
atomic failure, insertion IDs, process type/identity queries, collider replacement,
sleep/freeze, stale/foreign contexts, and repeated world allocation/cleanup.
The world can also be owned through the generic native resource manager and
retained after context shutdown.

A shared C/Lua/Rust golden trace checks sweep fraction, contact position and
normal, sliding, and unchanged state on initial-overlap failure. C/Lua run
`alpha7_world_parity`; Rust reads the same fixture. This compares native shape
movement with Lua's process helper. It does not claim that Rust already has
Lua's automatic process transform or graphic-derived collider behavior.

The bounded `world` example and offline installed SDK consumer exercise real
world movement in both profiles. Stable workspace checks, Clippy/format,
compile-fail owner-thread checks and native ASan/UBSan cover this implementation.
Miri verifies the pure future and query-buffer helpers, not C geometry.

Native camera values and explicit animation playback are now also delivered;
see the [camera/animation guide](../api/rust-camera-animation.md). Automatic
process integration remains open.

The optional Rust atlas metadata and Aseprite clip services are now delivered;
see the [atlas guide](../api/rust-atlas.md). Image loading and process graph
selection remain open.

The owned Rust window and native keyboard service are delivered; see the
[window guide](../api/rust-window.md) and [keyboard acceptance](../api/keyboard.md#alpha7-acceptance).

Immediate Rust drawing, scoped clip/scroll and owned images now use the native
backend; see the [drawing/image guide](../api/rust-drawing.md). Queued frame uses
retain image data through native drawing completion.

Remaining A7.6 work includes the shared native visual property/graph layer,
asset libraries and selection, automatic animation, draw collection/text/fade,
main/explicit/follow cameras, remaining platform graphics, mouse/controller/text input, audio and lifetimes,
headless graph override, contextual world/process movement and the complete
three-language graphics smoke matrix. The [native gap map](2.0.0-alpha.7-native-gaps.md)
remains the operation-level contract for that work.

See the [Rust collision guide](../api/rust-collision.md) for runnable usage and
failure/ownership behavior. No API family was moved out of alpha.7.

Local verification passed: 45 Rust workspace tests and nine doctests in each
profile; bounded counter/world examples; installed external consumer; SDK
rejection, Clippy and format checks. The C-only suite passed 50 tests, and the
Lua headless suite passed 160, including both new three-language parity traces.
Native ASan/UBSan passed all 45 Rust tests. Miri verifies seven pure helper
tests; native geometry itself is outside the interpreter.

The implementation passed the full host CI on commit `ceaf11a`; see the
[lifecycle host evidence](2.0.0-alpha.7-lifecycle.md#host-evidence). A subsequent
lifecycle-only test refinement raises the combined workspace count from 44 to
45 without changing collision implementation or fixtures.
