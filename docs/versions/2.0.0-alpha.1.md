# 2.0.0-alpha.1: initial C runtime

Status: initial alpha.1 implementation, not a complete release. The earlier engine and its LÖVE examples remain available. The executable includes Lua 5.4.8 and links raylib 5.5. CMake downloads Lua and raylib into the build directory on the first build and verifies their SHA-256 hashes. The executable contains compiled Lua. Dependency versions and notices remain in their sources.

## Build and run

You need CMake 3.20 or later, a C/C++ compiler, and a network connection for the first Lua and raylib download. On macOS:

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/malvado-run examples/alpha-hello/main.lua
```

Press Escape or close the window to exit. `malvado-run --headless game.lua` runs without a window. Headless scripts must terminate their processes. To use local sources, set `-DFETCHCONTENT_SOURCE_DIR_RAYLIB=/path/to/raylib-5.5` and `-DFETCHCONTENT_SOURCE_DIR_LUA=/path/to/lua-5.4.8`. The developer must verify their origin and version.

## API in this cut

The API includes `require("malvado")`, `process(fn)`, a `{...}` constructor that returns an ID, `frame()`, `start(init, options)`, `clear_screen(r,g,b)`, `key("escape")`, `draw_text(text,x,y,size)`, `font(size,r?,g?,b?,a?)`, `write(font,x,y,text)`, `change_text(id,text)`, and `delete_text(id)`. Fonts use the raylib default font. Text remains visible until it is removed or the runtime closes. `draw_text` draws for a tick; call it before each `frame`. `write` is persistent. Alignment and optional position/font parameters in `change_text` remain pending. Processes created during a tick run on the next tick. `frame()` outside a process fails. A process exception prints a traceback and returns a nonzero exit status.

Graphics mode uses a 60-tick-per-second accumulator independent of rendering, with at most five catch-up ticks per presentation. Dropped time is counted internally. The C clock accepts injected deltas in tests. Headless mode advances one tick per iteration. Some resource management, external fonts, and compatibility with old examples remain pending. Window opening, text drawing, and closing have been tested on macOS; interactive visual acceptance and Linux validation remain pending. Android and Windows are validated in alpha.6. Resolve the historical-code license conflict before publication.
