# Alpha.6 redesign verification

These results cover completed increments, not the complete alpha.6 candidate.
The tested revision for each increment is the commit that introduces its
checked item and this evidence entry. The commit subjects identify those
revisions in Git history. No public C symbols changed in these increments.

## A6-05: contextual collision and world wrappers

Revision: `feat(lua): add contextual collision and world movement`.

- `mise run test-headless`: 140/140 passed.
- `mise run test-c`: 42/42 passed.
- `mise run test`: 140/140 passed.
- `mise run test-visual`: 44/44 passed on the local graphics backend.
- `git diff --check`: passed.

New tests `lua_contextual_world` and `lua_contextual_world_start` cover both
entry forms, actual coroutine context, explicit calls from initialization and
nested coroutines, world replacement and retention/GC, query order and identity,
collider defaults/disabling/overrides, invalid calls without movement, hit data,
actual displacement, and dead targets. Existing process/world collision and
broad-phase benchmarks passed. The migrated collision and world examples passed
headless behavior checks and graphical example checks. Global import tests
cover collisions, repeat import and atomic failure for the callable namespace.

The C-only suite covers the unchanged native engine; the new wrappers are Lua
binding behavior. Local graphics results do not certify all target backends.
Candidate CI and remaining redesign capabilities are still open under A6-12.
