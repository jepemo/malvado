# Alpha.6 redesign verification

These results cover completed increments, not the complete alpha.6 candidate.
The tested revision for each increment is the commit that introduces its
checked item and this evidence entry. The commit subjects identify those
revisions in Git history. No public C symbols changed in these increments.

## A6-05: contextual collision and world wrappers

Revision: `feat(lua): add contextual collision and world movement`.

- `mise run test-headless`: 140/140 passed.
- `mise run test-c`: 42/42 passed.
- `mise run test`: 140/140 passed.
- `mise run test-visual`: 44/44 passed on the local graphics backend.
- `git diff --check`: passed.

New tests `lua_contextual_world` and `lua_contextual_world_start` cover both
entry forms, actual coroutine context, explicit calls from initialization and
nested coroutines, world replacement and retention/GC, query order and identity,
collider defaults/disabling/overrides, invalid calls without movement, hit data,
actual displacement, and dead targets. Existing process/world collision and
broad-phase benchmarks passed. The migrated collision and world examples passed
headless behavior checks and graphical example checks. Global import tests
cover collisions, repeat import and atomic failure for the callable namespace.

The C-only suite covers the unchanged native engine; the new wrappers are Lua
binding behavior. Local graphics results do not certify all target backends.
Candidate CI and remaining redesign capabilities are still open under A6-12.

## A6-06: minimal geometric constructors

Revision: `feat(lua): expose minimal graphic constructors`.

- `mise run test-headless`: 141/141 passed.
- `mise run test`: 141/141 passed.
- `mise run test-visual`: 44/44 passed on the local graphics backend.
- Configured and built `build-lua-no-assets` with raylib and assets disabled;
  10/10 selected context, geometry, import, inventory and collision/world
  regression tests passed. This checks that the wrappers do not require assets.
- `git diff --check`: passed.

`lua_minimal_graphics` verifies global/module/namespace constructor identity,
standard Lua `load`, invalid dimensions/options/colors/pivots, immutable values,
geometry and collider parity, visual-only region/scroll state, and descriptor
retention/cleanup. `lua_import_globals` checks every new name for atomic import
conflicts and repeat imports. Existing graphics/process regressions remain.

`visual_graphics_process` now uses the minimal constructors and checks transformed
rectangles, circles, RGB/RGBA colors, center/top-left pivots, z ordering, and an
opaque white default unaffected by `set_color`. The collision/world and
region/scroll example checks verify the migrated calls, clipping and pixels.
Namespace and method examples/tests remain in the existing regression suite.

Immediate drawing coordinates, fill functions and color state are unchanged.
The previous C-only result remains applicable: this increment adds Lua aliases
and no native API or core changes. This is not full candidate CI certification.

## A6-02: unified asset loading

Revision: `feat(lua): load supported assets through one entry point`.

- `mise run test-headless`: 142/142 passed.
- `mise run test`: 142/142 passed.
- `mise run test-c-assets`: 49/49 passed, including native parser/allocation,
  conversion and installed SDK checks.
- `mise run test-visual`: 45/45 passed on the local graphics backend.
- Asset-disabled/headless build: 5/5 selected import/inventory/image checks passed.
- `git diff --check`: passed.

`lua_asset_loader` checks content/schema routing, explicit formats, invalid and
unknown options, unsupported/ambiguous/malformed sources, file/path failures,
headless image limits, metadata lookup, original/converted FPG fidelity and GC.
`visual_asset_loader` checks all supported formats, paths relative to metadata,
missing images, actual atlas/manifest dimensions, retained resources and rendered
PNG/atlas/Aseprite/original/converted colors and transparency. The Aseprite and
FPG examples now use the loader and pass their existing visual checks.

The loader adds Lua routing and reuses existing native parsers and managed
images. No native public symbols changed. Metadata-only libraries do not prove
rendering support without images; their documented limits remain explicit.
