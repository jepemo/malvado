# Contribution instructions

- Write documentation, README files, examples, and code comments in English using ASD-STE100 Simplified Technical English. Use short sentences, one meaning per word, and consistent technical terms. Preserve code identifiers, proper names, and quoted source material.
- Make user-facing documentation exceptionally easy to read, friendly, and welcoming. Explain what the reader needs to understand and do, with concise steps and practical examples. Be as brief as possible without omitting useful context. Use the original root `README.md` as a reference for its approachable, example-led style.
- Start each Malvado C source and header file with the complete ASCII logo header, attribution, and SPDX license identifier, as in `src/main.c`. Do not change third-party notices or third-party source files.
- Follow the [C style guide](docs/development/c-style.md).
